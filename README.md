# 🚀 AI IT & GitHub Digest Bot (с локальной памятью)

Умный дайджест-бот, который мониторит GitHub, отбирает самые интересные инструменты и проекты по 5 темам, генерирует AI-выжимки без рекламы и воды, и сохраняет всё в локальную память на твоем компьютере.

---

## 🎯 5 ключевых тем дайджеста

1. 🤖 **ИИ, Боты & Нейросети** (LLM, AI-агенты, боты, модели машинного обучения, rea analyzer)
2. 🛡️ **Хакинг & Кибербезопасность** (пентест, reverse engineering, exploit-инструменты, защита)
3. 💻 **Программирование & DevTools** (новые языки, фреймворки, компиляторы, утилиты для кода)
4. 🚀 **DevOps & Сисадмин** (Docker, Kubernetes, Linux, мониторинг, автоматизация инфраструктуры)
5. 🛠️ **Необычные & Полезные тулзы** (Awesome-списки, CLI-утилиты для терминала, автоматизация рутины)

---

## 🧠 Локальная память (SQLite)
Бот хранит базу данных `memory.db` прямо на твоем компьютере:
- Запоминает все найденные репозитории и даты обнаружения.
- Не спамит дубликатами.
- Позволяет сохранять понравившиеся проекты в **⭐ Избранное**.
- Кэширует AI-ответы, экономя время и запросы.

## ⚡ Быстрый старт (Локально на твоем ПК)

### 1. Перейди в папку проекта:
```bash
cd /home/defor/ai-digest-bot
```

### 2. Запуск в режиме терминала (CLI) — без настройки Telegram:
Ты можешь потестировать работу прямо в консоли одной командой:
```bash
uv run python main.py --cli
```

### 3. Запуск Telegram-бота:
1. Открой файл `.env` в любом редакторе:
   ```bash
   nano .env
   # или используй любой графический редактор
   ```
2. Вставь туда свой токен от [@BotFather](https://t.me/BotFather):
   ```env
   TELEGRAM_BOT_TOKEN=твой_токен_здесь
   GEMINI_API_KEY=твой_ключ_здесь  # опционально, для AI-разборов
   ```
3. Запусти бота:
   ```bash
   uv run python main.py --bot
   ```
4. Открой своего бота в Telegram и нажми `/start` или `/digest`!

## ☁️ Бесплатный авто-запуск в облаке (GitHub Actions)
Чтобы бот обновлялся сам без включенного компьютера:
1. Создай новый репозиторий на GitHub (например, `my-digest-bot`).
2. Запушь проект в свой репозиторий:
   ```bash
   git init
   git add .
   git commit -m "feat: initial ai digest bot"
   git remote add origin https://github.com/ТВОЙ_НИК/my-digest-bot.git
   git branch -M main
   git push -u origin main
   ```
3. В настройках своего репозитория перейди в:
   `Settings` -> `Secrets and variables` -> `Actions` -> `New repository secret`
4. Добавь секреты:
   - `TELEGRAM_BOT_TOKEN`
   - `GEMINI_API_KEY`
5. Готово! Файл `.github/workflows/daily_digest.yml` будет автоматически запускаться каждое утро.
